* 🎯 Org Focus HUD

*Org Focus HUD* is a distraction-free, monotasking execution cockpit for GNU Emacs [[https://orgmode.org/][Org-mode]].

It locks your attention exclusively onto your *single currently active or scheduled task*, hiding the rest of your agenda and backlog to eliminate context switching, decision fatigue, and schedule drift.

Press =?= at any time inside the cockpit to view shortcuts:
#+begin_example
  CAPTURE (Zero context switching)   ACTIONS & PACING
  ─────────────────────────────────  ──────────────────────────────────────────
  [k] + Checklist / bullet item      [RET] Toggle item [ ] ↔ [X]
  [M-j] / [M-k] Move item down / up  [r]   Refresh node details
  [M-h] / [M-l] Outdent / Indent     [d]   Mark DONE & Advance
  [l] + Log Work Done ([timestamp])  [w]   Wait on this & Advance
  [n] + Quick Note                   [+]   Extend effort (+15m)
  [s] + Child Subtask                [p]   Pause / Resume Clock
  [a] + Sibling Task (after this)    [q]   Minimize HUD
  [[] / []] Scroll Work Log          [?]   Hide shortcuts help
  [o] Open in Other Window           [O]   Jump to Org File
#+end_example

* 🚀 Key Features

- *Distraction-Free Monotasking*: Eliminates future task clutter, showing only the task you should be working on right now.
- *Real-Time Pacing & Visual Progress*: Live progress bar comparing clocked elapsed time against estimated effort, with automatic overrun warnings.
- *Hierarchical Checklist Management*: Full in-cockpit checklist viewer and editor supporting nested checklists and plain bullets.
- *Option 2a Surgical Item Reordering*: Move checklist items up or down with =M-k= / =M-j= across intervening body paragraphs, source code blocks, and diagrams without disturbing non-list text.
- *Contextual Item Insertion*: Press =k= on any list item to insert a new item directly beneath it inheriting indentation, or press =k= anywhere else to append to the end of lists.
- *In-Cockpit Capture*: Log work done with inactive timestamps (=l=), capture quick notes (=n=), create child subtasks (=s=), or queue sibling tasks (=a=) without losing flow.
- *Evil / Spacemacs Compatible*: Single-key shortcuts work out of the box in Evil normal and motion states.
- *Zero Hard Dependencies*: Works out of the box with vanilla Org mode using standard =org-clock= and =:Effort:= properties.
- *First-Class Scheduler Integration*: Seamlessly integrates with [[https://github.com/SSD2019/org-auto-scheduler][org-auto-scheduler]] for dynamic repacking, automatic advance to next scheduled tasks, and calendar sync.

* ⌨️ Keybindings Reference

| Key | Action | Description |
|-----+--------+-------------|
| =TAB= / =S-TAB= | Next/Prev Checklist | Navigate directly between checklist items in the HUD |
| =k= | Add Checklist / Bullet | Contextual addition: inserts below cursor item matching indentation; if not on item, appends at end of lists across body |
| =RET= | Toggle Checklist | Toggle checkbox =[ ]= ↔ =[X]=, or convert plain bullet to =[ ]= |
| =M-k= / =M-<up>= | Move Item Up | Surgically swap item block with predecessor across intervening body text/images |
| =M-j= / =M-<down>= | Move Item Down | Surgically swap item block with successor across intervening body text/images |
| =M-h= / =M-<left>= | Outdent Item | Promote item block (-2 spaces), preserving relative child indentation |
| =M-l= / =M-<right>= | Indent Item | Demote item block (+2 spaces), preserving relative child indentation |
| =r= / =g= | Refresh Node Details | Refresh HUD from underlying Org buffer (updates effort, time, bullets) |
| =l= | Log Work Done | Prompt for work done and append =- [YYYY-MM-DD Day HH:MM] <work>= under =:LOGBOOK:= |
| =[= / =]= | Scroll Work Log | Scroll visible window in the fixed-size Work Log section (older / newer) |
| =n= | Add Note | Prompt for note and append timestamped entry in drawer |
| =s= | Add Subtask | Create child headline =** TODO <title>= with optional effort |
| =a= | Add Sibling | Create sibling task =* TODO <title>= queued directly after current task |
| =d= | Mark DONE & Advance | Mark task =DONE=, clock out, and auto-clock into the next scheduled task |
| =w= | Wait on This & Advance | Prompt for note & tickler date, move to =WAITING=, and advance |
| =+= / === | Extend (+15m) | Extend current task effort; triggers repacking when scheduler is loaded |
| =p= | Pause / Resume | Toggle =org-clock-out= / =org-clock-in= |
| =o= | Jump to Org (Other Window) | Reveal headline in original Org buffer in other window |
| =O= | Jump to Org (Same Window) | Reveal headline in original Org buffer in current window |
| =c= | Clock in Task | Select and clock into any scheduled task for today |
| =?= | Toggle Shortcuts Legend | Toggle the in-cockpit shortcuts legend on/off |
| =q= | Minimize | Dismiss Focus HUD window (clock remains running) |

* 📦 Installation

** Straight.el
#+begin_src emacs-lisp
(straight-use-package
 '(org-focus-hud :type git :host github :repo "SSD2019/org-focus-hud"))
#+end_src

** Manual
Clone the repository and add it to your load-path:
#+begin_src emacs-lisp
(add-to-list 'load-path "~/.emacs.d/plugins/org-focus-hud")
(require 'org-focus-hud)
#+end_src

** Use-Package
#+begin_src emacs-lisp
(use-package org-focus-hud
  :bind ("C-c f" . org-focus-hud)
  :config
  ;; Optional: Customize refresh interval in seconds
  (setq org-focus-hud-refresh-interval 15))
#+end_src

* 🔗 Integration with Org Auto Scheduler

If you use [[https://github.com/SSD2019/org-auto-scheduler][org-auto-scheduler]], Focus HUD automatically hooks into the scheduler:
- Pressing =+= ripples and repacks downstream schedule slots.
- Pressing =d= or =w= automatically advances and clocks into the next auto-scheduled task for today.
- Pressing =c= provides a completion list of today's scheduled slots.
